# Work Requirement 3

Small Python networking exercise using the socket module.

## How to run

Download the python file to your computer and run with any code viewer, f.ex. VS Code.

Run the script with: python3 hostname.py

## Reflection

In Module 5, I started to understand better what actually happens between a browser and a web server. Before this, I mostly knew how a browser loads a website from the frontend side.

Being already a little familiar with Python's standard library, I tried the socket module for the first time. It was interesting to see a small practical example of how hostnames and IP addresses are connected, and I was genuinely surprised by how simple this task was to complete.

The networking terminology was probably the most confusing part for me at first, especially TCP/IP, sockets, and HTTP, because they are related but have different roles, and I was learning about them for the first time.
